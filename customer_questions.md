# Discovery Questions for the ShreeRaksha Project Team

Below are the 5 operational and technical questions for the next discovery session to prepare the voice agent for production:

1. **Policy Database Integration API**: 
How will the voice agent query your policy database in real-time? We need a low-latency API that can retrieve the policyholder's name, vehicle model, and coverage status using either the vehicle registration number or the caller's mobile number.

2. **Telephony Routing and Transfer Queue Configuration**: 
How should standard vs. critical escalations be routed on your telephony system? We need to configure separate IVR endpoints for the general helpdesk and the specialized claims team (e.g., for third-party injuries). Additionally, how should the short context summary generated by the agent be sent to the human representative's screen?

3. **Claims CRM Data Formats**: 
What validation rules and formatting requirements does your backend Claims CRM enforce for intake fields? We need to align the data types captured by the agent (dates, license formats, registration numbers) with your database schema to prevent submission failures.

4. **SMS Gateway and Location Tracking**: 
How does your SMS system determine which network garages to recommend? We need to know if the garage list should be filtered by the city/location verbally captured by the agent, or if we can integrate mobile network location services (LBS) to send the closest active workshops.

5. **Failed/Dropped Call Protocols**: 
What is the follow-up protocol for incomplete claims registrations or dropped calls? If a caller hangs up due to an emergency or poor network roadside, should the system trigger an automated outbound callback or alert a human claims rep to follow up?
