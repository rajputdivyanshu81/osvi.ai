# Osvi AI — FDE Assignment

This repository contains the deliverables for the Osvi AI Forward-Deployed Engineer (FDE) assignment. 

## Project Deliverables
1. **System Prompt**: Core instructions for the voice agent (`system_prompt.md`).
2. **First Message**: The opening greeting spoken by the voice agent (`first_message.md`).
3. **Rationale**: Explanations of tone, flows, and design decisions (`rationale.md`).
4. **Discovery Questions**: Top 5 questions for the customer during onboarding (`discovery_questions.md`).

## Workflow Phases
- **Phase 1**: Understand requirements, business type, persona, and success criteria.
- **Phase 2**: Create and align on the implementation plan.
- **Phase 3**: Iteratively write and refine the deliverables.
- **Phase 4**: Perform final quality checks.
